# 账号管理实施与验收

2026-10-18。对应 product-design.md 阶段 A 的首个可用版本。

## 已实现

- 账号页从列表旁常驻编辑表单改为管理表格。搜索、分组、语言、启停状态、缺规则筛选可组合；40 条分页，返回/刷新保留筛选、页码、选择及表格滚动位置（当前标签页 sessionStorage）。
- 跨页勾选、本页勾选、全部匹配选择和清空；批量动作说明包括筛选外已选对象。账号按名称排序。
- 独立详情路由，内容定位、制作规则、关联批次三个标签。新增目标市场和禁用表达；旧账号可缺省这两项。受众、风格、规格缺失逐项提示，“基础规则齐全”不代表可以生成。
- 批量修改只提交勾选字段，留空表示清除，语言仍必填；启停也可批量处理。每账号携带 revision，只改匹配版本，冲突及未确认项保留选择，成功项取消选择。批量接口每次最多 200 项，UI 每块 100 项；单块原子写入，跨块可能部分完成。
- TSV 粘贴/UTF-8 文件读取（上限 4 MiB），可选择表头和列映射。逐行列出新增、已有跳过、错误与原始行号；40 条分页预览；下载错误文本；只导入有效行。修正后重新校验，已有账号不覆盖。
- 关联批次显示计划数量、当时语言和规格快照，并可进入批次。它是批次关系，不声称已支持作品历史。新增市场/禁用表达会写入新批次任务需求，旧快照保持原样。

## 文件归属

- apps/web/accounts.js：账号列表、详情、导入、批量修改；从 bulk.js 拆出。
- apps/web/accounts-model.js：字段定义、缺失项、带映射的逐行导入校验。
- apps/web/style.css：账号模块作用域；表格列宽和移动布局不复用旧任务列表的特定列规则。
- packages/bulk/index.mjs：兼容字段扩展、批量修改、账号关联批次查询。
- packages/application/index.mjs：HTTP/桌面共同接口。
- apps/api/server.mjs：新增前端模块资源白名单。
- test/accounts.test.mjs：映射错误/重复/跳过、跨页 ID 更新、部分冲突、非法字段和快照保护。

## 尚未覆盖与后续

- 阶段 A 仍可继续加入标签体系、保存命名视图、细分画幅/时长/字幕规则以及直接关联具体内容任务；本次维持已有“输出规格”字段，未将所有产品设计项标为完成。
- 目前读取 TSV，不直接解析 .xlsx；文件读取中途异常未做专门故障注入。输入错误逐行呈现，导入过程中网络中断有部分完成提示，但本轮未做断联专项 UI 验收。
- 仍采用单运行时文件写入；大量关联批次查询依次读取文件，尚未建立数据库索引。
- 未做运营人员独立任务测试，不能由自动化通过推断业务效率提升。真实制作、素材库、审核与交付未在本轮实现。
- 下一业务切片是商品事实 + 手工内容分配 + 缺失检查 + 计划保存/导出，避免批次仅复制同质需求。
