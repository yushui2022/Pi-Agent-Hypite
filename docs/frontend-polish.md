# 2026-10-18 前端工作区精修

本轮目标：参考用户的《从 Demo 到企业级质感：前端升级执行指南》、SkuMotion 和 WenCode 前端经验，把视频复刻首页和项目详情整理为可持续使用的工作区。保留 Pi Studio 身份、紫色操作强调、现有原生 JS 栈、私有空间与制作准备范围，不照搬其他项目的品牌和营销声明。

## 实际调整

- 首页从居中大表单和装饰横幅，改为参考导入、制作路线与场景要求。登录后显示最多三个真实项目的继续入口；读取失败可原位重试。
- 参考文件支持选择、拖放、本地播放、大小/时长、更换和移除。文件选择不会上传；确认导入后才创建项目和传输。多文件误拖、空文件、类型/大小错误、浏览器编码不支持均有说明。
- 预览 URL 在更换、移除、导航和退出时释放。认证续接保留文件与要求；上传期间锁定表单。未保存保护和失败保留项目沿用现有规则。
- 导航采用统一 SVG 图标，补充 favicon；收敛标题、辅助信息、控件、边界与主题。移除不再使用的装饰横幅/海报规则，避免继续堆叠首页覆盖样式。
- 项目默认显示当前参考；素材有图片缩略图和明确选中态。替换位置有编号和分组，保存操作保持可达；标签页支持方向键、Home/End，新增位置及变更类型后恢复焦点。
- 手机保留六个导航入口，压缩项目状态区；深浅主题、减少动态效果和可见焦点保持一致。

## 模块与执行顺序

1. `apps/saas-web/home.js` 管理首页及本地预览生命周期；`app.js` 继续负责路由、登录和上传提交。
2. `icons.js` / `favicon.svg` 提供本地图标；`style.css` 管理宿主与页面，`components.css` 管理共享控件，`tokens.css` 继续提供颜色与尺寸。
3. `apps/web/remix.js` 优化项目媒体和键盘交互；SaaS 的缩略图和位置分组通过宿主条件启用，保留本地工作台入口。
4. API 静态路由和构建清单同步新增文件；开发服务和 Caddy 的 CSP 仅为本地视频预览增加 `media-src blob:`，没有开放外部脚本或媒体来源。

## 真实风险与边界

本地预览依赖浏览器编码支持；无法播放不等于文件不可导入，服务端仍执行实际内容校验。512 MiB 上限沿用原规则，本轮没有上传 512 MiB 文件做性能验证。最近项目按创建时间排列，不表示最后编辑时间。视频生成、Pi/Hypit SaaS 执行、计费和公网部署均未在本轮完成。

前端新增文件必须同时更新 API 静态路由和 `scripts/build-saas-web.mjs`；本地服务进程需重启后才能识别新增路由。回退时按上述模块撤销展示改动，不删除项目数据库或用户素材。
