# P1a 原生桌面验收清单

2026-10-18。对象为实际 Tauri WebView2，使用独立测试数据；不以浏览器访问 4317 代替桌面验收。

| 声明/控件 | 功能检查与状态 | 视觉证据 |
|---|---|---|
| 启动/列表 | 原生窗口加载、本地 IPC 读取任务，空列表可创建 | 原始窗口尺寸、空列表 |
| 创建/编辑/保存 | 从界面创建、修改、保存；重启后读取 | 详情与保存状态 |
| 离开/关闭 | 未保存返回列表或关闭窗口：留在页面/放弃两条路径；进行中操作阻止关闭 | 退出确认对话框 |
| Pi | 实际接入检查、运行记录、停止；无模型禁用制作 | Agent 完成/取消状态 |
| Hypit | 放置可信技术 fixture，界面运行 check/plan；不存在路径显示错误 | 检查成功/失败记录 |
| 复制/搜索/筛选/排序 | 复制需求、独立修改、筛选与清除 | 列表多记录 |
| 主题/尺寸/服务 | 浅色→深色→系统，最小窗口可操作，服务状态符合实际 | 两种主题、最小尺寸、服务页 |
| 退出资源 | 正常关闭及工作中退出后无残留 Node/Pi；重启保留记录 | 进程与数据检查 |

异常探索至少覆盖：未保存时重复导航、无模型尝试制作、无效工程路径、重复关闭请求。导出文件与安装包属于后续独立验收，未验收项不能宣称已完成。

截图保存在 output/playwright/；调试端口仅用于本地验收进程，不在正常启动命令默认开启。

## 2026-10-18 实测结果

本机 Windows 原生 Tauri 2.12.4 / WebView2，通过 Playwright CDP 连接真实 `http://tauri.localhost/` 窗口完成操作，不使用 HTTP 开发网页或模拟 IPC 返回。初始 WebView 为 1220×820；通过原生窗口调整至 729×536，均未发现横向溢出、对话框遮挡或无法点击的主要控件；详情为纵向滚动布局。

- 创建任务 `job_6f742da9-990b-4e07-a0a9-7cc10b1646f5`，界面保存“保存后的桌面要求”；退出、重新启动后读回相同内容。复制并独立改名的变体为 `job_8a73737a-2f3c-42f5-b6db-3b7af52e7498`，原始任务不变。
- 页内返回和原生 WM_CLOSE 都触发未保存确认。“继续编辑”保留输入；“放弃修改并离开”退出且不持久化草稿。工程检查期间发出原生关闭请求，实际观察到 `操作正在进行，请稍候` → `检查通过，结果已保存`，窗口保持打开。
- 点击“检查引擎接入”，真实 Pi 接入成功，会话 `01a14c99-e405-734b-8ca8-d97adcf6b1c8`；再次启动并点击“停止会话”，界面显示“已停止”。无模型时“准备工程”保持禁用。
- 在该隔离任务工程中复制仓库技术 fixture 后，通过界面执行 `check main.svml` 和 `plan build.svrun`，结果均通过并可重启读取。输入 `missing.svml` 显示明确错误，不记录为成功。
- 验证复制、搜索“独立变体”得到 1/2、清除筛选、技术样例空状态、全部/制作需求筛选、三种排序、深色/浅色/系统主题、服务状态页。
- 探索发现 Esc 放弃新建后残留输入，现已补齐表单重置；重建桌面程序后复测，再次新建输入为空。原生关闭保护同时加入重复关闭请求防重入。
- 两次正常退出均为退出码 0。第二次退出前记录宿主 71260、运行时 26896、Pi 141396、conhost 138076，退出后这些 PID 均不存在，9431 无监听。该次 Pi 在退出时序中已完成，因此不将它当作“退出强制取消未完成任务”的独立证明；主动停止与 Job Object 回收已有各自测试。
- Playwright 收集到的页面异常为 0；14/14 Node 测试与 1/1 Rust Windows 进程树测试通过。
