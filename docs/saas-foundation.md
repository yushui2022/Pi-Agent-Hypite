# SaaS 第一切片实施记录 · 2026-10-18

目标：注册/登录 → 用户私有空间 → 项目 → 素材上传/预览 → 替换方案/批次计划。当前是本机开发验证版，不是正式可售 SaaS，也未完成整个 S1。

## 运行与模块

- `npm run saas:dev`，访问 http://127.0.0.1:4320，自行注册开发账号。
- `apps/saas-web`：登录注册、私有空间页面、会话失效清理；复用 `apps/web/remix.js` 的素材/方案/批次界面。
- `apps/saas-api/server.mjs`：独立 HTTP API，服务端决定空间归属，项目和媒体逐请求鉴权；仅监听 127.0.0.1，拒绝跨站修改。
- `packages/saas/store.mjs`：SQLite 用户、空间、成员、会话、项目文档；密码使用带随机盐的 scrypt，数据库仅保存会话摘要，Cookie 为 HttpOnly/SameSite=Strict，12 小时有效，退出立即撤销。
- `packages/remix/index.mjs`：增加可替换项目存储接口和受鉴权媒体读取接口，旧本地模式保持兼容。
- `test/saas.test.mjs`：双用户隔离、伪造项目编号冲突、媒体 Range、退出和重启恢复。

数据默认 `.data/saas/saas.sqlite`；媒体 `.data/saas/media/<workspace>/`，均位于 G 盘并被 Git 忽略。`SAAS_DATA_ROOT` 可指定独立测试数据目录；`SAAS_PORT` 可指定端口。旧本地工作台数据不自动迁入，避免将历史本地素材分配给错误用户。每空间最多 100 项目，单文件 512 MiB；尚无整体存储配额。

## 验证结果

- `npm test`：22/22，通过原有本地工作台及新增 SaaS 回归。
- Edge 实测注册、项目创建、上传真实 WebM 和 PNG；视频 duration 2.618468 秒、readyState 4，可播放。
- 实测保存文字替换位置、建立批次、刷新恢复、退出后重新登录恢复项目。
- 第二用户项目列表为空、直接请求首用户素材 404；退出后的素材请求 401。自动测试另验证服务重启后会话与项目恢复。
- 检查深/浅主题与 390px 窄屏，窄屏无水平溢出；修复一次前端常量赋值错误后，完整操作未再出现 pageerror。
- 浏览器测试在开发数据中留下两个 `@example.test` 测试账号及明确命名的测试项目，素材来自 G 盘 QA fixture，不是用户原始素材。

## 下一步与真实风险

1. 将 SQLite 存储适配器迁为 PostgreSQL，并引入 schema migration、备份恢复与并发事务验证；当前 SQLite 使用 Node 24 的实验性内置接口，适合本轮本地验证。
2. 对象存储、上传总配额、素材删除/保留策略、邮箱验证/找回密码、HTTPS Secure Cookie、线上限流和运营管理仍需完成。当前 HTTP 本机 Cookie 未启用 Secure，不应直接改监听地址发布公网。
3. 接入持久任务队列和 Worker，明确失败/重试/幂等、真实费用和作品归档，再接一种真实生成或替换方式。
4. 当前 SaaS API 只调用自有 remix 准备模块，未启动 Pi/Hypit 执行。Pi/Hypit 源码仍保留在既有集成；Hypit 对外托管许可未解决前不发布其 SaaS 能力。
5. React 前端迁移、支付/积分、多成员邀请、模型选择、成片下载均未实现。现有页面复用是先验证业务隔离的增量选择，不代表目标架构已经全部交付。

验收必须基于真实输入和产物；目前批次保存是制作计划，成品库保持真实空状态。
