## 修复的实际问题

1. FFmpeg 发布版 loader 依赖浏览器 location；适配后直接接受 Worker 预编译 Wasm 模块，不使用 XHR 加载或浏览器 Worker。
2. 独立编码的 AAC 逐段复制拼接产生时间戳回退。改为画面复制拼接、最终连续混音并编码 AAC，避免每个接缝叠加音频编码延迟。
3. libass 返回成功但没有可见文字。通过真实帧发现后，首版固定双行改用 drawtext 与显式字体文件；加入像素和负例检查。
4. Worker 的 Request 不支持 redirect:error；模型传输改为 manual，并对非成功状态直接失败，不跟随重定向或自动重试。
5. TypeBox 明确关闭请求阶段的动态编译，采用解释型校验；非法参数、未知工具和越界素材均不能执行。
6. 部署打包扫描共享 dist 会给 Pi 附带 Wasm；改为独立 dist/media、dist/agent，并关闭 Pi 的附加模块扫描。
