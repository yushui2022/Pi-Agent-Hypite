## 参考与设计依据

公开页面文本可确认视频/图片/智能体分类、参考重构入口及模板。自动浏览器访问遭 Cloudflare 验证，未尝试绕过，无法取得可比较的完整原站截图。检索没有确认可复用的官方前端源码许可证，因此全部 UI 自行实现，未复制对方代码、媒体、商标、模型宣传、活动或追踪脚本。

布局复杂度按 L3 创作门户处理；后端业务不从 Pollo 推断。自己的界面采用深色侧栏、居中创作输入、专题卡、模板列表；这些是实施选择，不能冒充原站实测样式。模板图为 CSS 原创概念示意，不是假造生成成果。

## 真实交互

- 首页游客可浏览；输入想法 → 登录/注册 → 自动继续创建项目，完整 brief 持久化。
- 视频改编接现有素材导入、方案、批次；AI 图片与智能体仅展示准确的未开放状态和可用替代入口。
- 模板预填创作想法；切换页面带未保存保护。
- 素材空间汇总当前用户项目素材，图片/视频/音频仍走鉴权 API；作品页真实空状态。
- 桌面侧栏、390px 手机导航、登录对话框、手机账号退出、深浅主题。
