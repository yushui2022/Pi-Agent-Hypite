## 模块职责

| 模块 | 主要对象 / 判断 | 主要动作 | 状态与恢复 |
| --- | --- | --- | --- |
| 开始复刻 | 参考视频与可选要求 | 导入并创建项目 | 校验、真实上传进度、重复提交保护、失败保留已建项目 |
| 复刻项目 | 项目→参考→方案→批次 | 根据缺项继续准备 | 搜索/阶段/排序/分页；返回保留筛选；清除筛选与首次空态区分 |
| 项目详情 | 当前方案与版本上下文 | 完善参考、配置替换、安排批次 | 展示下一步；已有编辑与版本冲突保护保持不变 |
| 替换素材库 | 私有项目媒体 | 预览并定位所属项目 | 名称/项目/类型/用途筛选；文件缺失说明；分页 |
| 制作任务 | 批次快照及各变体 | 核对缺项、进入对应批次 | 搜索/项目/资料状态；明确未执行；展开缺项 |
| 成品库 | 实际制作产物 | 当前引导查看计划 | 当前真实空态，不将上传素材或计划计为成品 |

准备阶段由真实数据推导，不写回数据库。项目阶段描述当前方案；任务缺项描述批次的独立快照，两者不能互相代替。素材“替换素材”仅指不是当前参考的项目素材，不意味着已经分配给某个位置。

## 组件与状态边界

- 宿主：app.js 负责路由、账号和离开保护；共享数据不跨退出保留。
- 展示：components.js 提供 Button、PageHeader、Badge、Field、Toolbar、EmptyState、Loading、ErrorState、Pager；不访问网络或持久化。原生 input/select/dialog 保持键盘行为。
- 业务控制器：workspace.js 读取私有项目，限制最多 5 个并行详情请求；所有结果仍经 API 鉴权。列表每页 12 条，离开再返回保留页面内筛选与页码；刷新或退出不保留，未宣称跨设备同步。
- 领域展示规则：workspace-model.js 计算下一步、按批次快照检查素材、搜索和分页。
- 视觉：tokens.css 是 SaaS 的语义色/尺寸入口，components.css 是后加载的共享控件与业务消费者样式。旧本地/桌面入口不会加载新主题；remix.js 通过可选上下文回调复用新展示。
- 组件展示：`/#components`，无业务写入，用于检查同一组件在不同状态/主题下的呈现。

## 执行与验证

顺序：审计正式入口并保存基线 → 项目/素材/任务状态和查找 → 共享组件/令牌 → 正式宿主验证 → 更新构建白名单与正常入口。

风险：共享按钮规则影响保存/上传；刷新列表可能覆盖用户输入；过期异步响应可能展示旧账号内容；状态计算可能把“准备齐全”误称为完成。处理：保留现有 guard；筛选数据仅页面内存，退出清空；挂载检查当前路由版本；所有准备标签明确“尚未提交执行”。
