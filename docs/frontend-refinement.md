# Pi Studio 前端升级记录

日期：2026-10-18。入口：http://127.0.0.1:4320/#home 。

## 目标与依据

根据用户提供的前端执行指南、SkuMotion、橙色 SaaS 与 WenCode 经验，围绕“导入参考 → 配置替换 → 安排批次 → 查看成品”整理界面。核心问题是导航占据手机首屏、工作页缺少视觉层级、项目缺少可辨识入口、多个面板叠加后像表单演示。沿用当前技术栈和真实接口。

## 已实施

| 文件/模块 | 变化与用途 |
| --- | --- |
| `index.html`、`app.js`、`icons.js` | 分组导航、可收起桌面侧栏、手机原生抽屉；外观偏好同步、标签及关闭行为、导航后的焦点位置 |
| `home.js`、`style.css` | 参考视频与改编要求分区；突出主操作，流程说明按需展开；保留原创光影背景和场景插图，手机首屏可开始创建 |
| `workspace.js` | 项目封面卡片/紧凑列表切换；真实项目、素材、批次数量；简洁筛选栏与结果计数；素材预览和批次信息分层 |
| `components.js`、`components.css`、`tokens.css` | 统一颜色、按钮、空状态、骨架加载、错误反馈；适配长标题与窄屏；保留键盘焦点和减少动效 |
| `apps/web/remix.js` | SaaS 项目详情使用四个带序号步骤，替换方案减少重复外框；现有保存与版本逻辑继续复用 |

项目封面来自当前用户上传的参考视频。缺参考项目使用空态，不以场景插图冒充用户作品。插图仅用于创作入口。制作任务显示实际保存批次及资料状态，不把资料准备完成显示成视频生成成功。

## 真实边界与后续风险

- 本轮交付为前端体验升级。视频生成、计费和公网部署没有新增实现，不能按完整商业产品验收。
- 当前项目列表读取项目详情后在浏览器筛选分页；大量项目需要服务端分页。参考视频封面采用 metadata 预加载，生产环境应生成独立缩略图，避免大型媒体带来的请求开销。
- 浏览器实测使用本机 Chromium/Edge；手机尺寸属于浏览器模拟，未验证 iOS Safari 的编码兼容性或真实触屏设备。
- 持续维护主题令牌与组件层；新增样式应写回所属组件，避免继续堆叠相互覆盖的页面规则。
